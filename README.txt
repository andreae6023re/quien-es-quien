# ¿Quién es quién? personalizado

Incluye los 32 personajes de la imagen proporcionada.

## Modos
- En persona: dos jugadores usando el mismo dispositivo.
- A distancia: sala con código mediante PeerJS/WebRTC.

## Uso
Abre `index.html` en un navegador moderno.

Nota: el modo a distancia necesita conexión a Internet para cargar PeerJS y establecer la conexión entre navegadores. Para publicar la app, basta con subir esta carpeta a un alojamiento web estático.
